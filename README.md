### Projeto em destaque

**[Hora Marcada API](https://github.com/mateusmarinhooo/hora-marcada-api)** · Python, FastAPI e SQLite

Uma API para consultar horários, reservar atendimentos e cancelar agendamentos. A regra central é simples: cada horário aceita uma única reserva. Os testes usam um banco em memória para verificar que a segunda tentativa é recusada e que o cancelamento libera o horário novamente.
